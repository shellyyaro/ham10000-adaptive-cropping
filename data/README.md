# Data layout

The HAM10000 dataset is not stored in Git. Place it here:

```text
data/HAM10000/
├── HAM10000_metadata.csv
├── HAM10000_images_part_1/
└── HAM10000_images_part_2/
```

Alternatively, set `HAM10000_ROOT` to a directory with the same contents.

Generated ensemble masks are written to `data/generated_masks/` and contain:

- `fused_masks_train.npz`
- `fused_masks_val.npz`
- `fused_masks_test.npz`
- `fusion_config.json`
- `model_sources.csv`

The NPZ files are intentionally ignored by Git because they can be regenerated by stage 2.
